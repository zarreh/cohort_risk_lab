# Data profile

Generated by `docs/generate_plots.py` from the actual built cohort — `make
docs-assets` regenerates these charts and CI fails if the committed files
drift from what it produces (PORTFOLIO_PLAN_V3.md §9.4).

The cohort is [Synthea](https://synthetichealth.github.io/synthea/)
(Apache-2.0, MITRE Corporation) synthetic patients, Massachusetts, seed and
population size committed in `data/synthea.config.json`. Every date has
been shifted per-patient before this cohort was built — see
`data/deidentify.py` and D-A12-2 in [decisions](../architecture/decisions/index.md).

## Disclosure: the injected access gap

Synthea generates realised cost from utilisation with no differential
access by race, so this cohort's utilisation and spend fields have been
deliberately adjusted for one stratum, at equal illness burden, per the
seeded and committed `data/access_gap.config.json`. This is what makes the
label-choice experiment (Phase 4) demonstrate the Obermeyer et al. (Science,
2019) failure mode rather than merely claim to. See D-A12-2.
